# TaskWeaver 安装版 E2E 验收清单

用于发版前验证打包产物；先使用隔离的 `.app` 目录，不覆盖用户当前安装。每项记录构建版本、运行环境、结果和日志/截图路径。

## 构建与启动

- [ ] 从待发布 commit 的干净工作区构建，记录 commit、`package.json` 版本和产物路径。
- [ ] 检查 `app.asar` 的 renderer/backend 文件，以及 `Contents/Resources/taskweaver-z-runtime` 的 Host runtime、preset 和 MCP 配置均来自同一构建。
- [ ] 首次启动成功；窗口可关闭并重新打开；退出应用后没有遗留 TaskWeaver Host 进程。
- [ ] 新用户数据目录可启动；已有用户数据目录可启动且会话列表可加载。

## 聊天、工具和权限

- [ ] 新建会话并发送普通问题；回复正文、Think 折叠、用量/上下文 meter 可见。
- [ ] 对工作区文件执行一次只读 `read` 或 `grep`；工具进度出现，结果与文件内容一致。
- [ ] 在 `ask` 权限模式下触发一次写操作；审批面板显示目标路径和操作，拒绝后工作区文件不变。
- [ ] 允许一次受控写操作；改动在文件 diff 中可见，并能通过 Git 检查点查看或还原。
- [ ] 中断运行中的任务；当前会话停止，另一个会话仍能正常工作。

## 会话与长任务

- [ ] 新增一条 follow-up 并验证它按队列执行；队列中的内容可查看、编辑和移除。
- [ ] 创建 Plan/Todo 或 DAG 任务；进度持续更新，取消后不再产生新工具调用。
- [ ] 重启应用后恢复最近会话；消息顺序、工具行、Plan/Todo 状态和模型用量没有重复或缺失。
- [ ] 对有足够历史的会话触发 Compact；确认 Host 历史缩短，摘要行在 UI 中显示一次。
