# TaskWeaver 前端 UI 优化总结

## 优化目标
参考 DSH（DeepSeek Harness）设计风格，优化 TaskWeaver 的对话界面，重点改进思考卡片（thinking cards）和工具卡片（tool cards）的视觉呈现。

## 完成的优化

### 1. 思考卡片（DshThinkBlock）优化

#### 视觉改进
- **更大的图标尺寸**: 从 14px 增加到 16px，提升视觉层级
- **优化的行高**: 统一使用 24px 行高，匹配 DSH 的 14px/24px 标准
- **改进的间距**: 增加容器边距（6px 0 10px），提供更好的呼吸感
- **增强的悬停效果**: 
  - 添加背景色变化 `rgba(255, 255, 255, 0.04)`
  - 图标颜色变为蓝色 `var(--accent-blue)`
  - 图标轻微缩放效果 `scale(1.1)`

#### 交互优化
- **更流畅的动画**: 使用 cubic-bezier 曲线实现 chevron 旋转
- **优化的展开内容**:
  - 增加内边距（10px 12px → 12px 14px）
  - 更大的圆角（6px → 10px）
  - 提升最大高度限制（360px → 480px）
  - 改进的文本样式（14px/24px 行高）

#### 运行状态动画
- 保持 DSH 的扫光动画效果
- 优化动画宽度从 280px 到 300px
- 支持 `prefers-reduced-motion` 无障碍访问

### 2. 工具卡片（ToolTraceCard）优化

#### 视觉增强
- **更大的图标**: 从 14px 增加到 16px
- **优化的卡片样式**:
  - 增加内边距（8px 10px → 10px 12px）
  - 更大的圆角（8px → 10px）
  - 更深的背景色 `rgba(0, 0, 0, 0.25)`
  - 添加悬停状态背景 `rgba(0, 0, 0, 0.35)`

#### 状态指示改进
- **运行状态**: 更明显的蓝色边框 `rgba(59, 130, 246, 0.4)`
- **错误状态**: 更清晰的红色边框 `rgba(239, 68, 68, 0.4)`
- **取消状态**: 柔和的灰色边框 `rgba(148, 163, 184, 0.35)`

#### 工具名称样式
- 添加独立的 `.tool-trace-name` 样式
- 使用等宽字体 `var(--font-mono)`
- 字体大小 13px，字重 500
- 改进的字母间距 `-0.01em`

#### 代码输出区域
- **命令区域**:
  - 更深的背景 `rgba(0, 0, 0, 0.4)`
  - 更亮的文字颜色 `#e4e4e7`
  - 增加内边距（8px 10px → 10px 12px）
  - 字体大小从 11px 增加到 12px

- **输出区域**:
  - 保持绿色主题但增强对比度
  - 改进的边框透明度 `rgba(34, 197, 94, 0.2)`
  - 统一的内边距和字体大小

#### 交互细节
- **Details 按钮**: 
  - 更大的点击区域（3px 6px padding）
  - 更明显的悬停效果
  - 改进的图标尺寸（13px → 14px）

- **路径按钮**:
  - 添加悬停下划线动画
  - 颜色渐变效果（#93c5fd → #bfdbfe）
  - 更好的禁用状态不透明度（0.85 → 0.7）

### 3. 整体布局优化

#### 内容区块间距
- **assistant-turn-body**: 间距从 10px 增加到 12px
- **assistant-block-wrap**: 间距从 4px 增加到 6px
- **block-debug-chip**: 更大的内边距（3px 8px）和圆角（6px）

#### 时间戳显示
- 添加 `font-variant-numeric: tabular-nums` 实现数字等宽对齐
- 统一的字体大小和间距

## 设计原则

### 1. 层级清晰
- 使用渐进式尺寸和颜色强调重要信息
- 图标、标题、摘要形成清晰的视觉层级

### 2. 一致性
- 统一的圆角尺寸（6px, 8px, 10px）
- 统一的间距系统（4px, 6px, 8px, 10px, 12px）
- 统一的字体大小阶梯（11px, 12px, 13px, 14px）

### 3. 交互反馈
- 所有可交互元素都有清晰的悬停状态
- 使用渐变动画提供流畅的视觉反馈
- 适当的过渡时间（0.15s - 0.2s）

### 4. 深色模式优化
- 使用半透明黑色创建层次
- 柔和的边框透明度
- 保持良好的文字对比度

### 5. 无障碍访问
- 保留所有 ARIA 标签
- 支持键盘导航
- 支持 `prefers-reduced-motion`
- 使用语义化的状态指示

## 技术细节

### CSS 变量使用
```css
var(--bg-canvas)
var(--text)
var(--text-secondary)
var(--text-muted)
var(--text-hint)
var(--accent-blue)
var(--accent-green)
var(--font-mono)
```

### 关键动画
```css
@keyframes dsh-reasoning-row-sweep {
  0% { left: -300px; }
  90%, 100% { left: 100%; }
}
```

### 响应式考虑
- 使用 `min-width: 0` 处理文本截断
- `text-overflow: ellipsis` 处理长文本
- `overflow: auto` 处理超长内容
